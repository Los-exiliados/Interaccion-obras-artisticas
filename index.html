MediaPipe Hand Landmarker

Up to 4 hands · 21 joints each

Every hand is tracked and read on its own: positions, per-joint velocity, pinch, fingers and gesture state. The first two hands keep their identity when more appear in frame.

No hands detected. Raise one or more hands in front of the camera.

Serve this folder over http://localhost (for example python -m http.server 8080). Camera access and ES modules do not work from file://.

Read the live state from the console: window.handTracking.hands holds one object per hand, each with its own joints[], palm.velocity and events.
